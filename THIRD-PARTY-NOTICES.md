# Third-party components

OmniFetch includes these unmodified upstream binaries in its Windows portable
packages:

- **yt-dlp** — https://github.com/yt-dlp/yt-dlp (Unlicense and included
  third-party notices in the upstream release)
- **FFmpeg** — https://ffmpeg.org/ and the Windows builds used by the workflow
  (GPL build; the corresponding source and license are available from the
  upstream build project)

The application downloads updates from those upstream HTTPS release pages and
does not modify the downloaded binaries.
